Key finding

Edge Scanner has one in-process market-data path and one accepted-alert distribution path. The dashboard and other local programs consume signals from the same hub; they do not share brokerage authority.

Integration status: the current WebSocket is useful, but its sequence number is process-local. The durable, versioned trading-code contract is tracked in issue #17.
